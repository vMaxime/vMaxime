### 🦂 Le jeu du scorpion

Un morpion (tic-tac-toe) jouable à deux : chacun place ses croix et ses ronds
à tour de rôle, le premier à en aligner 3 gagne. Ouvrez simplement
[`scorpion.html`](./scorpion.html) dans un navigateur pour jouer.
